# Meu Notes

Aplicativo Android simples para anotações exclusivamente em texto.

## Recursos
- Criar, editar e excluir notas
- Salvamento automático no aparelho
- Pesquisa por título e conteúdo
- Lista simples com título, prévia e data
- Banco de dados local Room (não precisa de conta nem internet)

## Abrir e gerar APK
1. Extraia o ZIP.
2. Abra a pasta `MeuNotes` no Android Studio (versão recente).
3. Aguarde a sincronização do Gradle.
4. Selecione **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. O APK de depuração será gerado em `app/build/outputs/apk/debug/app-debug.apk`.

Requisitos: Android Studio recente, JDK 17 e Android SDK 35.

Este pacote contém o código-fonte do projeto. O APK ainda precisa ser compilado no Android Studio.
